# ⚡ Physics Simulation Hub & AI Lab

An interactive, web-based physics laboratory featuring real-time canvas simulations and a Gemini AI-powered tutor. Designed to help CBSE Class 11 & 12 students and NEET/JEE aspirants visualize abstract concepts, experiment with parameters, and master core physics principles.

🔗 **Live Simulation:** [View Live Web App](https://<your-username>.github.io/<your-repo-name>/)  index.html.html
🌐 **Main Study Portal:** [Physics Prasanth](https://physicsprasanth.wordpress.com/)

---

## 🎯 Key Features

- **Interactive Simulations**:
  - **Projectile Motion**: Real-time trajectory plotting, drag mechanics, target calculation, and velocity vector resolution.
  - **Double Pendulum**: High-precision Runge-Kutta 4th order (RK4) numerical integrator displaying deterministic chaos and conservation of energy.
  - **Gravitational Mechanics**: N-body orbital dynamics and planetary motion sandbox.
  - **Wave & Ray Optics**: Refraction, angle of incidence/refraction overlays, and Total Internal Reflection (TIR).
- **Gemini AI Physics Assistant**: Context-aware AI tutor providing instant step-by-step conceptual explanations, derivations, and exam-oriented quiz questions.
- **Zero Installation**: Runs completely in any modern web browser across desktop, tablet, and mobile.

## 🚀 Live Demo & Deployment

This project is deployed using **GitHub Pages**.

To deploy your own copy:
1. Fork or clone this repository.
2. Go to **Settings** > **Pages**.
3. Under **Branch**, select `main` (or `master`) and folder `/ (root)`.
4. Click **Save**. GitHub Pages will generate your public live URL within 1–2 minutes.
